# react-native-card-lens

A high-performance React Native library for multilingual business card scanning, OCR, QR code detection, and accurate structured information extraction.

## Installation


```sh
npm install react-native-card-lens
```


## Usage


```js
import { multiply } from 'react-native-card-lens';

// ...

const result = multiply(3, 7);
```
